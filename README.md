# PyProjects 🐍

Repositório dedicado ao desenvolvimento e à organização de pequenos projetos em Python, com foco na prática da programação, no aprendizado de novas bibliotecas e na criação de aplicações para resolver problemas do cotidiano.

Os projetos exploram diferentes conceitos, desde lógica de programação e manipulação de listas até interfaces gráficas, automação e ferramentas que utilizam recursos da internet.

## Tecnologias utilizadas

- **Python:** linguagem principal dos projetos.
- **Tkinter:** desenvolvimento de interfaces gráficas.
- **PyWebIO:** exibição de conteúdo e interação com o usuário.
- **yt-dlp:** ferramenta utilizada para download de vídeos.
- **Speedtest:** biblioteca para testar o desempenho da conexão com a internet.

## Projetos desenvolvidos

| Projeto | Descrição |
|---|---|
| `ChatBot.py` | Chatbot simples que responde a perguntas predefinidas e registra o histórico das conversas. |
| `Dissecando uma Variável.py` | Exercícios de análise e manipulação de variáveis em Python. |
| `IMC.py` | Programa para calcular o Índice de Massa Corporal (IMC). |
| `Internet speed tester.py` | Aplicação com interface gráfica para medir as velocidades de download e upload e a latência da conexão. |
| `Jogo da adivinhação.py` | Jogo interativo baseado em lógica de programação e estruturas condicionais. |
| `Sorteando um item na lista.py` | Programa que seleciona aleatoriamente um elemento de uma lista. |
| `Sorteando uma ordem na lista.py` | Aplicação que embaralha os elementos de uma lista aleatoriamente. |
| `Tocando Um Mp3.py` | Script relacionado à reprodução de arquivos de áudio MP3. |
| `YoutubeDownloader.py` | Aplicação para baixar vídeos do YouTube utilizando a biblioteca `yt-dlp`. |
| `conversor.py` | Programa de conversão. |
| `cronometro.py` | Aplicação de cronômetro. |
| `test.py` | Arquivo utilizado para testes e experimentações com Python. |

## Conceitos praticados

O desenvolvimento desses projetos permite praticar diferentes fundamentos da programação:

- Variáveis e tipos de dados.
- Estruturas condicionais e de repetição.
- Funções e organização do código.
- Manipulação de listas e strings.
- Entrada e saída de dados.
- Geração de valores aleatórios.
- Manipulação de arquivos.
- Desenvolvimento de interfaces gráficas.
- Utilização de bibliotecas externas.
- Tratamento de exceções.
- Integração com ferramentas e serviços externos.
